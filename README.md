# Radar SUPER Mobile

Versão mobile-first da app original `radar-super-v14.5.1R.html`, mantida fiel à lógica do indicador e ajustada para funcionar bem em telemóvel.

## Como correr

```bash
npm install
npm run dev
```

Depois abre no navegador ou no telemóvel usando o IP do computador e a porta 3000.

## Build de produção

```bash
npm run build
npm run preview
```

## Objetivo

- manter o mesmo motor SUPER BUY / SUPER SELL
- preservar os filtros, timeframes, ranking e UI original
- adaptar o layout para ecrãs móveis
- permitir instalação como app web em home screen

## Nota

Esta é uma transposição direta para ambiente mobile web, mantendo a lógica do ficheiro original. Se quiseres, no próximo passo posso converter isto para React Native/Expo ou para uma app híbrida com WebView.n
